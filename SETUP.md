# Repository Notes

This is the special GitHub profile repo (`KhaydenChetty/KhaydenChetty`) — its `README.md` renders at the top of [github.com/KhaydenChetty](https://github.com/KhaydenChetty).

## Structure

```text
README.md                    the profile itself
assets/header.svg            custom animated header (no external service)
assets/footer.svg            custom animated footer (no external service)
assets/projects/             project screenshots — add these
profile-3d-contrib/          generated by GitHub Actions, do not edit by hand
.github/workflows/           automation
```

## Automation

| Workflow | Schedule | Output |
| --- | --- | --- |
| `3d-contrib.yml` | daily, 18:00 UTC | `profile-3d-contrib/*.svg` committed to `main` |

That's the only workflow. It uses the built-in `GITHUB_TOKEN` — no secrets required.

The README currently shows `profile-night-view.svg`. Other variants the workflow generates, if you want to swap: `profile-night-rainbow.svg` (more colourful), `profile-gitblock.svg` (blockier), `profile-green-animate.svg` (animated).

### Removed in the redesign

The `metrics.yml` and `snake.yml` workflows were deleted along with their generated SVGs — the redesign cut the panels they fed. Two follow-ups:

1. **Delete the `METRICS_TOKEN` secret** — Settings → Secrets and variables → Actions. Nothing uses it now.
2. **Revoke the classic PAT** at [github.com/settings/tokens](https://github.com/settings/tokens) so it isn't left active.

The `output` branch (old snake artifacts) can also be deleted — it's unreferenced.

## Editing the header or footer

`assets/header.svg` and `assets/footer.svg` are hand-written SVG with CSS animations. Colours follow the profile palette:

```text
background   #05070A
primary      #00FFF0    cyan
secondary    #8B5CF6    purple
accent       #FF00FF    magenta
text         #E6EDF3
muted        #7D8590
border       #21262D
```

To preview a change, open the `.svg` file directly in a browser — animations run there exactly as they will on GitHub.

> Note: GitHub caches images through its camo proxy. After changing an SVG, a hard refresh (Ctrl+F5) may be needed to see the update on your profile.
